# 🏡 Airbnb Clone – Full Stack Web Development Project

## 📌 Project Overview

This project is an Airbnb-inspired web application developed as a Full Stack Web Development project. It allows users to explore property listings, create accounts, manage properties, make bookings, and share reviews.

## 🚀 Features

- User Registration and Login
- User Authentication and Logout
- View All Property Listings
- Search Properties by Location
- Add New Property Listings
- Edit and Delete Properties
- Property Booking with Check-in and Check-out Dates
- Booking Confirmation
- View My Bookings
- Cancel Bookings
- Add and Delete Reviews
- Property Owner Authorization

## ⚙️ Installation and Setup

1. Clone this repository:

```bash
git clone YOUR_GITHUB_REPOSITORY_URL
```

2. Navigate to the project folder:

```bash
cd airbnb-clone
```

3. Install dependencies:

```bash
npm install
```

4. Create a `.env` file in the project root and configure:

```env
MONGO_URL=your_mongodb_connection_string
SESSION_SECRET=your_secret_key
```

5. Start the application:

```bash
npx nodemon -L app.js
```

6. Open your browser:

```text
http://localhost:8080
```
